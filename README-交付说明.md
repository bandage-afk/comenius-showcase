# 小红书风格学习社区（Comenius）

> ℹ️ 这份文件是**开发过程日志**（按时间追加，记录每次 UI 调整），不是当前架构说明。
> 想了解现在的结构与怎么跑，请看 [README.md](./README.md)、[docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md)、
> [docs/DEPLOY.md](./docs/DEPLOY.md)。

React 19 + Vite + Tailwind CSS v4 构建的小红书风格学习社区，包含内容发现、笔记分享、个人主页、消息、创作者工具等页面。

## 运行

```bash
pnpm install
pnpm dev        # 开发服务器，默认 http://localhost:8443
pnpm build      # 生产构建，产物在 dist/
pnpm preview    # 预览生产构建
```
